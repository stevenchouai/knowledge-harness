One-minute public demo

Run it on a fake vault, then verify the receipt.

This static page is the shortest public-safe proof path for knowledge-harness. It shows the exact three steps a visitor should understand: run the demo, inspect the receipt, then clean up the temporary files.

1

Run demo

The demo creates a tiny fake Obsidian vault under a temporary root, assembles the normal dry-run prompt, writes run metadata, and saves a self-contained receipt. It does not read a real vault and it does not call Codex.

Copyable command

mkdir -p /tmp/kh-demo-proof
knowledge-harness demo --save-html /tmp/kh-demo-proof/receipt.html
2

Inspect receipt

Open the saved receipt and check the paths and safety claims. The receipt points to prompt.txt and run.json, so the proof can be checked from files instead of trusting the terminal output.

What to open

/tmp/kh-demo-proof/receipt.html

Then inspect the receipt paths:
prompt.txt
run.json
3

Clean up

The command prints the temporary demo root and its cleanup command. Remove that root when the check is done. The sample command below only removes the local receipt path from this walkthrough.

Cleanup command

rm -rf /tmp/kh-demo-proof

# Also run the cleanup command printed by knowledge-harness demo.

What to verify

  • fake_vault points to a temporary demo folder, not a real Obsidian vault.
  • metadata_file records dry_run=true and write_output=false.
  • The prepared command contains no --add-dir grant for a vault path.
  • The run directory has no last_message.txt, because Codex was not called.
  • The fake vault contains only AGENTS.md, PROMPTS.md, and wiki/_index.md.
  • config/harness.json, runs/, private notes, and credentials are not part of this demo.

This page is static HTML with inline CSS only. It contains no external scripts, no external stylesheets, no private vault content, and no private local paths.
